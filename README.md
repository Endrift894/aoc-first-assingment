# 3. Logging
- **Deployment Logs:** Build and deployment logs are monitored directly in GitHub Actions.
- **How to view logs:** Go to the GitHub repository -> Click the **Actions** tab -> Select the latest workflow run -> Click the job to view detailed build logs.
## 4. Rollback Steps
If an update breaks the live site, the project can be rolled back to a previous working version:
1. Open the GitHub repository and click on **Commits** (the history icon).
2. Locate the last working version of the code.
3. Revert the changes to restore the working version, which GitHub Pages will automatically re-deploy.
